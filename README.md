# Númina — sitio público

Este repositorio contiene únicamente:

- la página pública de descarga de Númina;
- la APK Android publicada;
- los manuales públicos de Vendedor y Administrador;
- recursos visuales mínimos de la portada.

El código fuente, las reglas, herramientas, documentación interna y demás archivos de desarrollo se mantienen en el repositorio privado separado.
